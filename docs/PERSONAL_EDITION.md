# 个人玩家版与每日导出规则

本次发行：1.3.2-diy.1。Windows x64。默认额度为每个设备每天10次，日界线为北京时间00:00。

## 哪些操作计次
完整制造任务成功保存后计一次。同一任务内的多个盘、多个板件或一个分板ZIP合计一次。重复领取已经完成的同一任务不重复扣除。取消或没有完成文件保存时释放预留次数；写入途中软件退出，重开后依据已登记的目标文件状态恢复，不简单把重启当成新额度。

草图编辑、图片/SVG摆放、3D预览、保存和打开.snapboard工程不计次。第11次新制造导出会被拒绝，已有工程、图片和已经生成的文件继续保留。

## 服务器与离线
首次使用及每日换新额度需要联网。设备生成自己的签名密钥，向https://auth.snapboard.cn请求服务端签发的当日凭据。客户端验证服务端签名、设备绑定、随机挑战与有效期；系统保护密钥用于本机加密存储。时间异常、缓存损坏和签名无效时不会静默重置次数。

本次个人版明确使用10次策略，不协商此前实验中的不限次策略。服务器需要部署对应的每日额度接口；源码自建不附发行私钥和运营后台。每台电脑的软件运行与素材计算在本机完成。

额度服务接收设备标识、公钥、签名、随机挑战、请求时间和已完成任务凭据；不接收图纸、原图、客户资料或3MF内容。本次编号用于来源对照，不是官方真伪证书。

## 数据与升级
默认本机数据在 %APPDATA%/SnapBoard DIY/workspace。卸载保留数据。旧SnapBoard或农场版的工程可通过“打开”导入，不需要复制授权缓存，不把别人的设备凭据发送给测试者。

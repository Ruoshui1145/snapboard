# 安装与第一次制作

1. 在GitHub Releases下载标有个人玩家版的Windows x64安装器及SHA256SUMS.txt。安装后打开“SnapBoard 个人玩家版”。
2. 首次联网取得每日10次额度。额度不可用时查看顶部个人玩家版状态，检查网络和北京时间；不要删除工程来尝试恢复额度。
3. 在板材设计中创建板型并标注毫米尺寸，设置厚度和打印机热床，分割后检查孔位。
4. 在纹理工作室导入图片或SVG并摆放；需要减材时进入镂空结构，选择保留方式与骨架，先看效果再应用。
5. 保存.snapboard工程，再导出3MF；在自己的切片软件中核对耗材、盘数、总厚度、图案面与打印方向。优先试打一小块。

## 配件与素材
公开安装包不带第三方Private模型集合。可以从设置→配件库导入自己的模型或有明确许可的.sbpack。软件截图里的配件与图案不代表都作为下载资产附带。

## 找回工程
菜单“文件→打开用户数据目录”可查看本机库。个人玩家版数据在 %APPDATA%/SnapBoard DIY/workspace；旧版工程使用打开文件导入。更新或卸载不应删除工程。保存位置选择外部目录后，请保证该目录仍可访问。

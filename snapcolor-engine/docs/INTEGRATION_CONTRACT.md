# 与 SnapBoard 的未来整合契约

## 当前阶段

当前 SnapBoard 不导入本包。新引擎仅在本目录构建和测试。

## 输入

未来由 SnapBoard 提供：

- 整板全局坐标下的目标像素或设计色；
- 板面有效区域 mask；
- 长圆孔、φ5孔、接缝、配件遮挡和安全边带 mask；
- 选定的 `.snapcolor.json` profile；
- 分板轮廓与打印方向。

## 输出

引擎返回：

- 每个像素/色区的配方ID；
- 每个配方的目标色、预测/实测色和 ΔE00；
- 每个层号×材料的二值掩膜；
- profile ID、哈希入口和引擎版本；
- 警告、色域外颜色与置信度；
- 可复现的优化参数。

## 禁止耦合

- 引擎不读取 Zustand store；
- 引擎不访问 DOM、Canvas 或 Three.js；
- 引擎不写入厂商完整配置模板；
- 引擎不认识现有第三方色彩模式；
- 旧项目迁移由 SnapBoard 适配层处理。

Bambu工程适配属于可选的本地外部工具边界：核心引擎始终先生成标准3MF；只有用户本机检测到Bambu Studio时，测试服务才调用其CLI生成厂商项目骨架。未来网页部署必须把该能力明确标为本地助手或服务器制造适配服务，不能假设普通浏览器可以直接执行桌面切片器。

## 整合门槛

只有在以下条件同时满足后才允许接入正式入口：

1. 当前 SnapBoard build和制造回归继续通过；
2. 引擎自身 `npm run verify` 通过；
3. 至少一套自主 `measured-prototype` profile；
4. 一张校准板和一张独立验证图完成实物复测；
5. Bambu Studio与OrcaSlicer打开输出无对象丢失；
6. 普通单材质导出不依赖本引擎。

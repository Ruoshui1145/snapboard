# SnapColor 工艺衍生产品路线

更新时间：2026-08-31

## 优先级1：可更换彩色表皮洞洞板

把5mm结构板和0.4–0.8mm装饰表皮分开：

- 结构板长期使用；
- 图案、宿舍主题、社团活动或季节版本只重打印薄表皮；
- 配件遮挡严重时只替换局部皮肤；
- 校色实验不再重复打印整块5mm板；
- 可以按图案包、校园主题包和个人定制收费。

可更换/模块化彩色面板在灯箱产品中已有用户需求，例如磁吸面框与模块化插片；SnapBoard的差异是同时具备异形轮廓、功能孔、装配和遮挡治理：

- <https://makerworld.com/en/models/167267>
- <https://makerworld.com/en/models/1553389-japanese-lithophane-lantern-modular-window-panel>

## 优先级2：基色自动选择的四卷料定制

针对用户图片分别计算不同锚定基色下的：

- 平均/P95/最大ΔE00；
- 可达色域；
- 换料次数和冲刷废料；
- 细碎区域与孔边风险；
- 打印时间和耗材成本。

输出“最高保真、最低成本、最少换料”三套方案。这一功能直接利用SnapColor基色约束与SnapBoard制造代价，比普通最近色匹配更具差异化。

## 优先级3：打印农场校色认证

平台向合作农场发放：

- E0重复性卡；
- 单耗材双背衬梯度包；
- 新批次哨兵卡；
- 真实孔边/接缝情境卡；
- 自动生成的工艺指纹与质量报告。

只有拥有有效profile的设备才能接收对应彩色订单。收入可以来自认证、复验、订单撮合和打印差价，而不必依赖关闭源代码。

## 优先级4：耗材批次profile市场

profile不是简单HEX列表，而是绑定打印机、喷嘴、PETG批次、层高、PEI表面、背衬和验证报告的数据包。平台可支持：

- 材料商提交；
- 农场复验；
- 用户评分；
- 版本和失效管理；
- 原始数据哈希与许可证。

未完成来源和验证的profile只能本地使用，不能进入公共库。

## 优先级5：昼夜双态与颜色—纹理面板

分别建立正面反射与背光profile，让同一块板：

- 白天作为有图案的功能洞洞板；
- 夜间由LED背板呈现另一种层次；
- 纹理PEI、平滑面和透明保护层成为可选表面产品。

模块化灯光板、可更换插片和背光框在MakerWorld已有成熟需求，说明“面板+框架+耗材包”比只卖单个3MF更容易形成完整产品：

- <https://makerworld.com/en/models/168659>
- <https://makerworld.com/cs/models/1476727-lithophane-3-size-frame-for-bambu-led-board-kit>

## 科创方向：触觉彩色信息板

将盲文、触觉路径、颜色分区、异形空间和洞洞板配件结合，可用于：

- 校园无障碍导览；
- 宿舍/实验室安全标识；
- 可更换课程图板；
- 触觉地图与低视力高对比信息板。

该方向同时涉及智能制造、图形算法、人因设计和工程验证，适合科创比赛与技术成果整理。

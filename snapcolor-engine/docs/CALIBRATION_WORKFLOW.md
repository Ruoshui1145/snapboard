# SnapColor 自主校色工作流

更新时间：2026-08-31

## 1. 目标

SnapColor 的校准不以“拍一张色卡并生成一个看起来接近的 LUT”为终点，而要形成可复现的制造档案：

```text
工艺锁定
→ 单耗材白/黑双背衬梯度
→ 四角透视校正与稳健采样
→ 单耗材衰减拟合
→ 光学基色候选比较
→ 分层覆盖组合实验
→ 重复样与盲留出样
→ 真实5mm板/孔边/接缝情境验证
→ measured-prototype / validated profile
```

### 240mm单盘快速模式

四色五层且背衬侧固定一个光学基色时，共有256个有效配方。240×240mm热床可以采用16×16布局：13mm色块、1mm间隔、8mm边距，总占用239×239mm。该模式适合手机/相机取色，中央取样区域应控制在色块中部，避免边缘与缝隙。

若使用较大测量孔径的分光测色仪，应切换15mm色块的仪器模式并接受自动拆盘。240mm单盘模式不适用于180mm级热床。

Lumina 的公开教程证明了白底/黑底成对梯度卡、同设备同曝光、完整Kit与四角校正的工程价值；SnapColor 只参考公开流程，重新设计数据格式、拟合、选样、质量门槛和3MF生成器，不复制其GPL代码、LUT、色卡资产或未公开2.0模型。

- Lumina梯度卡生成：<https://wiki.luminastudio.com.cn/zh/docs/tutorials/gradient-card-generate-print/>
- Lumina拍摄与提取：<https://wiki.luminastudio.com.cn/zh/docs/tutorials/gradient-card-extract-profile/>
- Lumina公开版本边界：<https://github.com/lumina-layer-studio/Lumina-Layers>

## 2. 三类“底”必须分开

| 概念 | 作用 | 是否进入颜色模型 |
|---|---|---|
| `structuralBase` | 5mm洞洞板强度、孔壁与装配 | 真实情境验证必须记录 |
| `opticalSubstrate` | 光学层后的白/黑/灰反射背衬 | 必须 |
| `anchorMaterial` | 四色配方中固定的光学基色 | 必须 |

光学基色可以和反射背衬、结构基材使用同一卷PETG，也可以分开；配置文件不得继续把三者合并成一个`baseColor`。

## 3. 双背衬梯度拟合

同一厚度下，近似写为：

```text
C_white(t) = F × (1 - T(t)) + B_white × T(t)
C_black(t) = F × (1 - T(t)) + B_black × T(t)
```

两式相减后，可以先估计：

```text
T(t) ≈ [C_white(t) - C_black(t)] / [B_white - B_black]
```

V1使用可解释指数基线：

```text
T(t) = exp(-k × t)
```

输出衰减系数`k`、TD10、单层遮盖率、材料本色估计和拟合RMSE。模型只用于缩小候选范围，正式颜色仍以组合实测与留出验证为准。

## 4. 工艺指纹

每次校准至少冻结：

- 打印机型号与序列；
- 喷嘴直径、喷嘴ID和使用状态；
- 光学层高与第一层高度；
- 喷嘴/热床温度；
- 表层速度、线宽、流量与Pressure Advance；
- 构建板型号、使用面、纹理、清洁方式；
- 面朝下/面朝上；
- 走线方向与板件热床方向；
- PETG品牌、SKU、颜色、批次、干燥条件；
- 环境湿度；
- 白/黑/灰背衬和5mm结构基材；
- 相机/仪器、光源、观察者、测量几何和日期。

PETG透光受致密度、均匀性、厚度、层高、流量和速度影响，不能把不同切片参数的档案混用：<https://bioresources.cnr.ncsu.edu/wp-content/uploads/2023/11/BioRes_19_1_500_Wang_J_Effect_Slicing_Param_Light_FDM_3D_Printed_PETG_23056.pdf>

## 5. E0–E5实验阶段

| 阶段 | 目标 | 关键输出 |
|---|---|---|
| E0 | 测量/拍摄重复性 | 同点、同卡、多次采集方差 |
| E1 | 单耗材与基色主效应 | 双背衬厚度曲线、初始光学参数 |
| E2 | A→B与B→A界面方向 | 有序相邻材料对覆盖 |
| E3 | 两色闭环 | 训练、留出、重复和端到端3MF |
| E4 | 三色模型 | 物理模型与经验残差比较 |
| E5 | 四色生产库 | 分层抽样、真实板情境与制造回归 |

`experimentPlanner`先覆盖“层位×材料”和有序相邻材料对，再按分层与最大最小汉明距离填充预算；重复样与留出样在排盘前确定性打散，避免与热床位置完全相关。

## 6. 摄影质量门槛

手机原型最低要求：

- 同一设备、镜头、距离、曝光、白平衡与对焦；
- 关闭HDR、滤镜、美颜和AI增强；
- 相机正对样板，两侧45°对称高显色光或漫射灯箱；
- 白底/黑底卡同一拍摄会话；
- 四角顺序固定为左上、右上、右下、左下；
- 取样只使用色块内部，不跨边界；
- 自动报告过曝/欠曝通道比例、拟合RMSE、单调性异常；
- 原图、四角、采样结果、拟合结果与软件版本共同保存。

正式方案优先使用分光测色仪，同时保存光谱、SCI/SCE、仪器与校准信息。色差统一使用CIEDE2000：<https://www.cie.co.at/publications/colorimetry-part-6-ciede2000-colour-difference-formula-1>

## 7. SnapBoard专属验证

纯色卡通过后，必须在真实5mm板上复测：

- 大面积板内；
- 5×15mm长孔附近；
- φ5连接孔附近；
- 分板接缝和外轮廓；
- 纹理PEI 0°/90°方向；
- 配件遮挡与留白区。

这一步把校色从独立画片工具升级为“结构—颜色联合制造”能力，也是SnapBoard与一般图像叠色软件的核心差异。

# 零件库与装配系统路线

更新时间：2026-08-26  
本文区分“当前已接线能力”和“后续计划”，当前完整项目说明见 [`PROJECT_DOCUMENTATION.md`](PROJECT_DOCUMENTATION.md)。

## 1. 格式策略

| 用途 | 首选 | 兼容 | 当前处理 |
|---|---|---|---|
| 网页预览 | GLB | 3MF / STL | 有 GLB 时优先使用；否则按模型格式加载 |
| 固定零件制造模型 | 3MF | STL | `model.print` 进入制造 3MF |
| 单个打印件 | STL/3MF | — | 资源包可直接提供制造模型 |
| 可编辑源文件归档 | STEP / SLDPRT | Parasolid | 只归档，不在浏览器中直接编辑 |
| 完整项目 | `.snapboard` + 3MF | JSON 制造清单 | `.snapboard` 保存编辑语义，3MF 保存制造网格 |

模型声明必须明确单位、Z 轴方向、默认朝向和安装锚点。不能只靠网格几何猜测“哪个钩子插哪个孔”。

## 2. 资源包结构

```text
配件资源包/<资源包名称>/
├── pack.json
├── parts/
│   └── <part-id>/
│       ├── part.json
│       ├── preview.glb       # 可选，网页预览优先
│       ├── model.3mf/.stl    # 预览或制造模型
│       └── source.step      # 可选源文件归档
└── designs/                 # 可选完整方案
```

`npm run parts:sync` 扫描资源包并生成 `public/partLibrary/`；开发服务器监听资源包变化并触发同步。普通用户导入的模型进入 `配件资源包/我的配件/`，当前支持 3MF、STL、GLB、GLTF。

除传统 `<包>/parts/<零件>/` 外，还支持 8 个大类根目录：`01-挂钩类` 到 `08-线缆整理类`。大类根不要求 `parts/`；裸模型会按“每个文件一个零件目录”归一化。分类词表集中在 `scripts/part-category-rules.mjs`，Vite API 与同步脚本共用，避免“线缆整理类”被通用“整理”词误分类。

## 3. `part.json` 关键语义

- `id/name/category`：稳定 ID、显示名和类别；
- `model.preview`：网页预览模型；
- `model.print`：制造导出模型，没有该字段时只预览不打印；
- `model.format/unit/upAxis/scale/orientation`：加载和制造朝向；
- `mount.mode`：`free`、`single`、`multi`；
- `mount.anchors[]`：局部位置、接受的孔型和装配约束；
- `defaultRotation`：默认绕安装法线旋转。

锚点类型：

- `slot`：仅匹配长圆孔；
- `round`：仅匹配圆孔；
- `either`：两种孔均可。

多锚点零件必须整体匹配孔位组合，不能通过缩放或拉伸零件解决孔距不一致。拖动预览会显示有效/无效状态和吸附高亮。

## 4. 当前已实现

- 资源包目录扫描、清单索引和网页缓存同步；
- 3MF、STL、GLB、GLTF 的预览加载；
- 配件拖放到 3D 板面；
- 单锚点和多锚点吸附的基础流程；
- 孔型匹配、旋转预览、碰撞/无效状态提示；
- 配件参数应用和制造模型导出；
- 3MF 中相同定义、相同参数的配件 object 复用；
- 缺少制造模型或模型损坏时导出警告，不伪造打印几何；
- 配件导入和标定接口写回 `part.json`。
- 网页批量导入单文件上限 200 MB，逐文件显示成功/失败并继续处理后续文件；
- 导入和改名弹窗通过 React Portal 挂到 `document.body`，中部限高滚动；
- `findPartManifest` 同时解析传统 `parts/` 与大类根布局；
- 长圆孔锚点保存局部 `axis`，与板孔长轴不平行的 90° 旋转会被拒绝；
- 正背面共享全局孔位占用集合，其他零件不能复用已占孔；
- 装配命中未开候选圆孔时执行幂等开孔，3D 和 3MF 同步变为真孔；
- `mount.contactZ` 记录贴板接触面的局部 Z，装配深度由接触面而不是安装柱端面决定；
- 旧长圆孔锚点缺少 `axis` 时显示“待补长孔方向”，打开标定器后自动探测，保存前不允许装配。
- 接触面作为独立定位项显示和保存；旧版误记的末尾圆孔可按严格共面规则恢复为 `contactZ`；
- 标定和拖拽中的长圆孔始终使用胶囊形覆盖，拖拽模型保持碳灰半透明并独立显示各锚点；
- 配件卡拖拽区与改名/设置按钮隔离，浏览器拖影使用已挂载的透明节点，避免拖出整张设置卡；
- 完整孔组尚未匹配时只显示最近一个兼容引导孔，匹配后切换为绿色精确吸附孔组；接近水平/竖直的采样轴会归正，避免小角度歪斜。
- 一套锚点支持正背面双向装配：固定视角服从正面/背面按钮，自由视角根据相机所在侧自动判断，并按侧翻转锚点、法向、长轴和接触面。
- 配件库吸顶浏览（摘要/导入/排序/分类常驻，列表滚动）+ 排序（默认资源序号/名称/类别/格式/标定状态，升降序）+ 自定义顺序拖拽（⠿ 手柄，写回 `part.json.sortOrder`）+ 单件信息设置（名称、说明、序号、分类、删除）+ 批量模式（复选、移动到分类、删除，走 `/api/part-library/batch` 目录级操作）。
- 复合洞洞板制造层由 3MF 父对象 components 绑定，配件/板件仍分开排盘；板件内部的基材、Lumina 光学层和质感贴面作为子零件独立分配耗材与切片参数。
- 纹理工作室支持 `surfaceMode=lumina` 多色版画和 `surfaceMode=veneer` 单材质 PETG 质感贴面，并支持普通基材颜色、表层颜色、表层厚度、基材填充率和纹理 PEI 细磨砂面。

## 5. 后续路线

| 优先级 | 工作 | 验收标准 |
|---|---|---|
| P0 | 装配撤销/重做覆盖更多边界情况 | 拖动、换孔、旋转、删除都可恢复 |
| P1 | 装配方案和 BOM | 项目可列出零件、数量、参数和制造文件 |
| P1 | 资源包版本、校验和迁移 | 错误包能定位文件和字段，旧包可迁移 |
| P1 | 搜索、收藏、缩略图 | 100+ 零件目录仍可快速定位 |
| P2 | STEP/OpenCascade WASM | 源文件可转为预览网格并保留单位/朝向 |
| P2 | `.sbpack` 打包导入导出 | ZIP 不允许执行脚本，路径不能越界 |
| P2 | 大模型分块和缓存 | 大型零件不会阻塞主线程或导致重复加载 |

## 6. 安全和兼容边界

- 资源包路径必须限制在 `配件资源包/` 内；
- 文件名、包 ID、零件 ID 必须做路径字符清理；
- 模型导入大小受请求体限制；
- 网格只在闭合和可制造校验通过后进入 3MF；
- `source.step` 等工业源文件目前只归档，不代表浏览器已支持编辑；
- 候选孔虚线是交互提示，不是配件安装实体，也不会进入制造输出。

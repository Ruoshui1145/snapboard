## 修复内容

1. **背面凹刻网格破面**：凹刻框与通孔作为独立holes直接传给三角剖分，触边/重叠关系导致8条异常边。仅对凹刻路径先执行平面差集，再由规范外环和内环挤出；保留闭合检查。原标记回归及普通/心形3MF回归通过。
2. **首次细分目录导入失败**：创建零件目录前未创建其父目录。现在先建立`partsDir`，独立HTTP回归确认新子目录首次导入成功、索引可读取。
3. **Electron命名报错**：Electron不支持`window.prompt()`。保存命名、新建项目、创建细分文件夹统一使用可等待的`textPrompt()`软件内对话框，保留确定、取消、Escape和焦点恢复。
4. **发布检查旧路径**：许可证校验改查当前`snapColorLut.ts`及其实际引用的9个LUT，原始来源与许可证继续保留，不恢复已迁出的旧资源。
5. **尺寸长小数遮挡**：分割列表与画布标签最多显示两位小数，原始几何精度不变。
6. **退出提示仍提开发命令**：确认文字改成软件退出与保存提醒。

## 封装结构

独立构建工程`desktop/`、生产暂存`desktop/payload/`、输出`release/desktop/`、用户数据`%APPDATA%/SnapBoard/workspace/`。API在构建时从现有配置提取并打成自包含JS，运行时不依赖Vite或开发目录。

首版安装包为Windows x64/NSIS，含Electron浏览器与Node运行时。关闭窗口会结束本地服务。会话鉴权仅允许软件自己的本地请求；渲染器没有Node权限。

## 素材与数据边界

安装包排除开发者个人工程和Private模型包；当前默认配件列表为空，可导入自有配件。装配宿主、板型库和颜色LUT正常内置。发给朋友时只发安装exe，无需压缩整个仓库。

随包附许可证、来源说明和构建输入源码zip。源代码快照只含构建需要的程序/配置/资源，不含商业文档和个人工程。

# 从草图到实体

1. 在 2D 草图中绘制墙面外轮廓；
2. 使用内轮廓标记插座、开关或不可覆盖区域；
3. 用智能尺寸输入现实毫米尺寸；
4. 选择打印机有效区域并自动分板；
5. 检查长圆孔、固定孔、拼接边和圆角；
6. 在 3D 中装配挂钩、托盘、底座和紧固件；
7. 选择 PETG 基层、材质贴面或自定义图片；
8. 导出多盘 3MF 与降级制造包；
9. 在 Bambu Studio/OrcaSlicer 中核验；
10. 打印、编号、安装并回填测试数据。

:::warning 制造前必须核验
网页预览正确不等于切片正确。导出后必须检查盘位、对象数量、材料映射、孔洞、上下倒角和有效打印区域。
:::

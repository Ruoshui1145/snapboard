# 3MF 制造包

SnapBoard 输出可编辑项目快照和多盘 3MF。3MF 在浏览器端生成，包含制造网格、对象变换、材料/颜色意图和盘号；2D 尺寸、3D 虚线、面板标签、相机和拖拽辅助对象不会写入制造模型。

## 兼容边界

不同切片软件可能忽略供应商专用元数据，因此 3MF 使用标准 Core 网格，并将 Bambu/Orca 盘位映射放在 `Metadata/model_settings.config`；相同制造几何复用 object，多个摆放位置使用 build item 实例。

## 导出阻断条件

- 非闭合网格；
- 无向边未被恰好两个三角形共享；
- 盘号不是从 1 开始连续；
- 板件超出有效打印区域；
- 材料或对象映射缺失。

`plater_id` 必须为从 1 开始的连续盘号；旧版 0-based 盘号文件应重新导出。网格采用毫米单位，板件制造曲线使用高精度离散并加入配置的制造倒角。

# SnapBoard

SnapBoard 是一个面向 3D 打印洞洞板的浏览器设计与制造系统。用户画出墙面、床架、柜体和插座轮廓，系统自动分成适配热床的板件、生成孔位与拼接结构、装配配件，并导出多盘 3MF。

## 它解决什么问题

标准矩形洞洞板无法充分覆盖 L 型、阶梯型、带插座和床架遮挡的空间；通用 CAD 又要求用户理解建模、孔阵、热床分割、切片排盘和装配。SnapBoard 把这些步骤压缩为一条连续工作流。

```text
现实尺寸 → 2D 轮廓 → 自动分板与孔位 → 3D 装配 → 纹理/材料 → 多盘 3MF → 实体安装
```

## 当前完成度

- 2D 外轮廓、内孔、智能尺寸和原点吸附；
- 自动分板、板件融合、错列长圆孔与 5 mm 固定孔；
- 3D 板件、正反面配件装配、孔位占用和接触面；
- 配件资源包、模型导入、锚点标定和缩略图；
- PETG 基层、材质贴面、自定义图片与彩色表层；
- 多对象、多盘 3MF、打印机预设和降级制造包；
- 本地项目保存、导出进度和校园试点文档。

:::info 当前阶段
双面胶墙面板的基础生产链路已经能工作。当前重点是 X2D/P2S/AMS 预设、实体彩色样板、校内静载/疲劳测试和郑州校园试点。
:::

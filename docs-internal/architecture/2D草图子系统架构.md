## 一、文档定位

本文档是 SnapBoard 的 2D 草图子系统（总体架构 M1）的次级架构文档，用途：

1. **功能基准**：完整记录 SolidWorks 2D 草图（Sketch）的绘图实体、工具、几何关系、尺寸标注与底层算法清单（官方文档调研结论），作为 SnapBoard 草图功能的功能基准与"对标清单"。
2. **现状盘点**：核实并记录 SnapBoard 当前已实现的草图功能与技术底座（代码事实，非目标）。
3. **差距矩阵**：逐项对照 SolidWorks 功能与 SnapBoard 现状，标注优先级（P0/P1/P2/不适用），按产品定位（积木式 pegboard 组装工具，非通用 CAD）裁剪。
4. **演进指引**：给出目标数据模型、模块文件规划与实施路线图，供后续开发排期使用。

> 关联文档：《总体架构.md》（系统分层/模块划分/路线图）、《TECH_SPEC.md》（SKÅDIS 参数/数据模型/技术栈基准）。本文档引用而非重复两份文档的内容。

## 二、SolidWorks 2D 草图功能全景（调研结论）

> 来源：SOLIDWORKS Design Help 2024–2026 官方文档（链接见第八章）。每项标注官方英文名。注意：SolidWorks 草图的**求解器为 Siemens D-Cubed 2D DCM**（商用组件，与 CATIA/NX/Inventor/Fusion 同源），本节功能均以此为底座。

### 2.3 几何关系（Sketch Relations / Constraints）— 完整清单

| 官方英文名 | 中文 | 作用 |
|---|---|---|
| Coincident | 重合 | 点位于线/弧/椭圆上 |
| Midpoint | 中点 | 点保持在线段中点 |
| Concentric | 同心 | 两及以上弧共享圆心；或点保持于弧圆心 |
| Tangent | 相切 | 线/弧/样条之间单点相切 |
| Parallel | 平行 | 两线保持平行 |
| Perpendicular | 垂直 | 两线成 90° |
| Horizontal | 水平 | 线水平或点水平对齐 |
| Vertical | 竖直 | 线竖直或点竖直对齐 |
| Equal | 相等 | 线长相等或弧半径相等 |
| Symmetric | 对称 | 相对中心线等距且垂线对称 |
| Fix | 固定 | 锁定尺寸与位置（固定线端点仍可在无限线上滑动） |
| Fix Slot | 固定槽口 | 锁定槽口尺寸与位置 |
| Collinear | 共线 | 实体位于同一条无限线上 |
| Coradial | 共径 | 两弧共享圆心与半径 |
| Intersection | 交点 | 点保持在两线交点 |
| Equal Curvature | 等曲率 | 两条样条接触点 C2 连续 |
| Equal Slots | 相等槽口 | 槽口长度与半径相等 |
| Pierce | 穿透 | 草图点位于轴/边/曲线穿过草图平面处（扫掠引导线） |
| Merge Points | 合并点 | 两点合并为一点 |
| Doubled Distance | 双倍距离 | 到中心线的尺寸为实际距离两倍 |
| On Edge | 位于边线 | 模型边投影（转换实体引用自动生成） |
| （3D 专用）On Plane / On Surface / Tangent to Face / AlongX/Y/Z / ParallelYZ/ZX / Normal | — | 3D 草图方位关系 |
| （专项）Traction / Torsion Continuity | 牵引 / 扭转连续性 | 传动布局 / 样条连续专项 |

要点：关系作用于**无限直线/完整圆**而不只是草图段；样条内部点支持重合/同心/垂直/相切/中点/固定，端点额外支持水平/竖直/合并。

### 2.4 尺寸标注（Dimensions）

**智能尺寸 Smart Dimension（自动选型）**：线→线性、弧→半径、圆→直径、两斜线→角度、两平行线→线性、弧/圆与点→到中心线性、弧弧/圆圆→圆心距线性。指针位置切换方向（Pointer Lock 锁定类型）。

| 尺寸类型 | 说明 |
|---|---|
| 水平/竖直/对齐/线性 Horizontal/Vertical/Aligned/Linear | 线性尺寸方向随指针切换 |
| 角度 Angular | 两线夹角、弧端点夹角、两点间角度 |
| 半径 Radius / 直径 Diameter | 弧默认半径、圆默认直径 |
| 线性直径 Linear Diameter | 线性形式标注圆直径 |
| 弧长 Arc Length | 弧真实长度 |
| 坐标 Ordinate / 基准 Baseline / 链式 Chain / 路径长度 Path Length | 工程图类标注 |

**驱动 vs 从动**：驱动尺寸（driving）可改几何；从动/参考尺寸（Driven/Reference，灰色加括号）只读随模型更新；过约束时可转从动。

**方程式与数值联动**：方程式四视图（全局变量/草图方程式/尺寸视图/求解顺序）、链接数值 Link Values（改一改全）、条件语句、跨模型共享。

**标注显示（Dimension Palette）**：公差类型（None/Basic/Bilateral/Limit/Symmetric/MIN/MAX/Fit）、精度、样式、加括号、检验标注、尺寸线属性、双制尺寸。

### 2.5 底层算法与机制

| 机制 | 说明 |
|---|---|
| **变分式约束求解器** | Siemens D-Cubed 2D DCM：变分式（非顺序）求解；1991 年 John Owen 提出约束图分解为双连通分量（biconnected components）的算法；支持点/线/圆/椭圆/圆锥/样条/参数曲线与全类型约束；处理 well/over/under-defined 与"过约束但一致"配置；带符号尺寸、局部化求解（Localised Solving）、并行分区（v72+）、实例（Instances） |
| **自动几何关系推理（Inference）** | 绘制时显示推断线（虚线/高亮提示），自动推理端点/中点/交点/相切并即时预览；Automatic Relations 开关控制自动生成关系 |
| **拖动求解（Drag Solving）** | 拖动几何实时重新求解全部尺寸与约束维持设计意图；Automatic Solve / No Solve Move / Override Dims on Drag 设置 |
| **捕捉系统（Snap / Quick Snaps）** | 端点/草图点、中心点、中点、象限点、交点、最近点、相切、垂直、平行、水平/竖直直线、水平/竖直对齐点；网格捕捉（默认关）、长度捕捉、角度捕捉；捕捉结果直接产生对应几何关系 |
| **草图原点与坐标系** | 原点红色显示，捕捉原点产生重合关系；草图依附草图基准面与本地坐标系；Edit Sketch Plane 整体迁移草图 |

### 2.6 草图状态与诊断

| 状态 | 颜色 | 含义 |
|---|---|---|
| 欠定义 Under Defined | 蓝 | 缺少尺寸/关系，可拖拽改变；特征树前显示 (−) |
| 完全定义 Fully Defined | 黑 | 尺寸关系齐备无冗余，变更可预测 |
| 过定义 Over Defined | 红 | 冗余/冲突尺寸或关系 |
| 求解失败 | 粉=无解 / 黄=无效解 | "Item is Unsolvable / Item Conflicts" |

**SketchXpert（草图诊断器）**：诊断模式（列出全部可行解决方案集 Solution Sets，循环预览，Accept 采纳）+ 手动修复模式（列出冲突关系/尺寸，Delete/Suppress/Delete All，可撤销）。

## 五、目标数据模型扩展

当前模型（`types/geometry.ts`）：`Contour { points[], closed, shape?, center?, radius?, constraints[] }` — 折线/圆两类实体，约束内嵌于轮廓。

目标演进（渐进式，不破坏现有命令）：

```ts
// 阶段一（P0，与现状兼容）：Entity 化轮廓
type SketchEntity =
  | { kind: 'line'; p1: number; p2: number }            // 点索引引用
  | { kind: 'arc'; center: number; start: number; end: number; sweep: 'ccw' | 'cw' }
  | { kind: 'circle'; center: number; radius: number }
  | { kind: 'slot'; center1: number; center2: number; radius: number }  // 槽口 = 两半圆 + 两直线
  | { kind: 'spline'; points: number[] }                // P1

// 阶段一：几何关系独立化（与约束并列）
interface Relation {
  id: string
  type: 'horizontal' | 'vertical' | 'parallel' | 'perpendicular' | 'equal'
    | 'coincident' | 'tangent' | 'symmetric' | 'fix'
  entityRefs: Array<{ entityId: string; index?: number }>   // 实体/点索引
  status?: 'under' | 'fully' | 'over' | 'conflict'
}

// 阶段一：求解状态（P0 状态颜色编码）
interface SolveStatus {
  state: 'under' | 'fully' | 'over' | 'failed'
  conflictingIds: string[]
  redundantIds: string[]
}
```

说明：① 槽口参数与 SKÅDIS `HolePatternParams`（slotWidth/slotLength）同构，直接复用；② Constraint 保留"标注即约束"（driving 尺寸），新增 Relation 承载非尺寸几何关系；③ 点索引引用保证 planegcs primitives 映射简单（点索引 ↔ `p{i}` id）。

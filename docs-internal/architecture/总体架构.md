# SnapBoard 2.0 总体架构

> 洞洞板积木式组装设计工具 — 面向 3D 打印的垂直 CAD
> 版本: v2.0 | 更新: 2026-07-31 | 配套: [TECH_SPEC.md](../snapboard-v2/docs/TECH_SPEC.md)

## 一、产品概述

SnapBoard 是专为 **3D 打印洞洞板（pegboard）系统** 设计的浏览器端参数化设计工具。用户用 2D 草图绘制板子轮廓，系统按标准规格（SKÅDIS）自动生成孔阵列，超过打印床尺寸时自动分割并生成连接件，最后从内置零件库拖出配件自动吸附到孔位，形成完整的可打印方案。

### 核心流程

```
绘制轮廓(外轮廓+内轮廓开孔) → 自动分割(热床尺寸,最少块数) → 3D 成型(薄板+连接件) → 乐高式配件装配 → 导出打印
        (2D 自由草图)              (split)                 (extrude)              (吸附)            (STL)
```

> **2026-08 产品决策**：孔阵列（SKÅDIS）不再作为核心流程。洞洞板由用户自由绘制（任意轮廓 + 自画孔/槽口/圆角开孔），配件装配改为乐高式连接/吸附。

### 关键约束

| 约束 | 数值 | 说明 |
|------|------|------|
| 打印床尺寸 | ≤220mm | 触发自动分割 |
| 运输尺寸 | 可配置 | 同打印床限制 |
| ~~孔阵列规格~~ | ~~SKÅDIS 标准~~ | 已移除：板面孔位由用户 2D 草图自画（圆/槽口/圆角开孔） |
| 板厚 | 4mm | 3D 成型 |

## 二、系统分层

```
┌──────────────────────────────────────────────────────────┐
│                    浏览器 (React 18 + TS)                  │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌──────────────┐  │
│  │ UI 层   │  │ 交互层  │  │ 渲染层  │  │ 数据层       │  │
│  │ Toolbar │→│ 工具状态 │→│ Canvas  │  │ Zustand      │  │
│  │ Sidebar │  │ 命令模式 │  │ Three.js│  │ 命令历史     │  │
│  │ 面板    │  │ 拖拽吸附 │  │ GLB     │  │ Project      │  │
│  └─────────┘  └─────────┘  └─────────┘  └──────────────┘  │
│                   ↓ 核心算法 (纯 TS, 无 DOM 依赖)          │
│        ┌─────────────────────────────────────────────┐    │
│        │  holePattern.ts  孔阵列生成 (SKÅDIS)         │    │
│        │  split.ts        自动分割 (孔间中线)         │    │
│        │  connectors.ts   连接件生成                  │    │
│        │  boardMesh.ts    3D 板子 (Shape 布尔)        │    │
│        │  glbLoader.ts    零件加载 (缓存+变换)        │    │
│        └─────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────┘
                           │ REST (JSON)
                           ▼
┌──────────────────────────────────────────────────────────┐
│             后端 FastAPI (Python, 复用 module2-*)         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌─────────┐  │
│  │ 分割服务  │  │ 孔位生成  │  │ STL 生成 │  │ 打包    │  │
│  │ packer   │  │ hole_gen │  │ stl_gen  │  │ 3MF     │  │
│  └──────────┘  └──────────┘  └──────────┘  └─────────┘  │
│  shapely · trimesh · numpy                                │
└──────────────────────────────────────────────────────────┘
```

**原则**: 前端做交互/渲染，算法层纯 TS 无框架依赖，重计算（分割/STL）走后端。

## 三、模块划分

### M1. 2D 草图绘制

| 能力 | 实现 |
|------|------|
| 工具 | 选择/画笔/矩形/圆/圆心弧/三点弧/多边形/槽口/中心线/等距/修剪/智能尺寸 + 约束按钮 + 内外轮廓(开孔)切换 |
| 渲染 | Canvas 2D (自研, 世界坐标+相机变换) |
| 交互 | 平移(中键)/缩放(滚轮)/吸附 |
| 撤销 | 命令模式 (CreateContour/UpdatePoints/AddConstraint) |

### M2. ~~参数化孔阵列 (SKÅDIS)~~ — 已移除（产品决策 2026-08）

> 用户决定：不需要自动孔阵列。核心流程改为「2D 自由草图 → 自动分割 → 3D 装配」。
> `utils/holePattern.ts` 代码保留（可作参考/后续复用），不再接入流程，SKÅDIS 面板不开发。
> 板面孔位/开孔（圆、槽口、圆角开孔）由 M1 草图工具直接绘制。

### M3. 自动分割系统

| 能力 | 实现 |
|------|------|
| 触发 | 任一边 > maxPieceSize (默认 220) |
| 自动切割 | 贪心, 沿孔间中线 (spacing/2 处), 每块 ≤ 限制 |
| 手动切割 | 拖拽分割线, 吸附孔中线 |
| 连接件 | 沿分割边交错 pin (male/female), 复用 D_joint 规格 |
| 正反面 | 正面孔位(配件) / 反面凸起(连接) |

### M4. 零件库 (预建模 GLB)

```
partLibrary/
├── defs/*.json     参数 schema + GLB 引用
├── models/*.glb    SolidWorks 预建模 (零运行时几何计算)
└── index.json      分类/索引
```

- 参数修改 → 变换 GLB (scale/rotate), 不重建网格
- 大变化 → 加载不同尺寸变体
- 自定义零件 → 上传 STL/GLB (v2 后期)

### M5. 自动吸附装配

```
配件拖出 (DnD) → 3D 视口 hover 板子
  → 计算最近孔位 (欧几里得距离)
  → 高亮孔位 + 对齐指示
  → drop → PlacedPart { defId, boardId, holePos, rotation, params }
```

### M6. 导出

| 格式 | 用途 | 实现 |
|------|------|------|
| STL | 3D 打印 | 前端 three-stdlib STLExporter / 后端 trimesh |
| 3MF | 多材料 (远期) | 后端 py3mf |
| JSON | 项目文件 | 前端序列化 Project |

## 四、数据模型

```typescript
Project
├─ metadata { name, version }
├─ config  { pixelToMM, material }
└─ parts: Part[]
    └─ features: Feature[]
        ├─ SketchFeature { contours: Contour[] }
        └─ (Board 由 Sketch 升级: 轮廓 + 孔阵列 + 厚度 + 分割)

Board
├─ contour: Contour[]
├─ holePattern: HolePatternParams   (SKÅDIS)
├─ thickness: number
└─ split: { maxPieceSize, cuts: CutLine[] }

SplitPiece
├─ contour / holeRange
└─ connectors: Connector[]          (pin/clip, male/female)

PlacedPart
├─ defId → PartDefinition (GLB + params schema)
├─ boardId / holePos {row,col} / rotation
└─ params: Record<string, number>
```

## 五、关键设计决策

| 决策 | 理由 |
|------|------|
| 固定配件预建模 GLB | 零运行时几何计算, 加载即用 |
| 孔阵列参数表单驱动 | 不需约束求解器 (非自由尺寸) |
| 孔间中线切割 | 保证每块边缘孔完整 |
| 3D 孔用 Shape 层布尔 | 避免 three-bvh-csg 3D 布尔开销 |
| 命令模式 | 天然 undo/redo, 快照完整 |
| 算法层纯 TS | 可测试, 可移植到 worker |
| 后端复用 module2-segmentation | packer/hole_gen/stl_gen 已验证 |
